# M5072 - Aprenentatge Automàtic (Machine Learning)

## Descripció
Mòdul centrat en el disseny, desenvolupament i avaluació d'algorismes de Machine Learning. S'analitzen les diferents metodologies d'aprenentatge per extreure patrons a partir de conjunts de dades complexos.

## Continguts Principals
* **Aprenentatge Supervisat**: Algorismes de classificació i regressió (arbres de decisió, SVM, regressió lineal/logística).
* **Aprenentatge No Supervisat**: Algorismes d'agrupament (*clustering* com K-Means) i reducció de la dimensionalitat (PCA).
* **Aprenentatge per Reforç**: Principis d'agents, entorns, recompenses i la presa de decisions dinàmica.
* **Avaluació de Models**: Mètriques de rendiment (matriu de confusió, precisió, recall, F1-score) i optimització d'hiperparàmetres.

## Estructura del Directori
* `Apunts/`: Teoria sobre els algorismes i mètodes d'avaluació.
* `Practiques/`: Notebooks i codi pràctic d'entrenament de models.
